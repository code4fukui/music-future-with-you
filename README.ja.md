# 新幹線開業ウェルカムダンス

北陸新幹線の開業を機に、福井県によって制作された応援ソングとダンスの素材集です。楽曲データ、楽譜、歌詞データなどが含まれています。

## 機能

- 楽曲データ(FLAC、MP3)
- 楽譜データ(MIDI、PDF)
- 歌詞データ(TXT、PDF)

## ライセンス

音源および歌詞カードに関する著作権およびその他一切の権利は福井県が保有しています。北陸新幹線の開業機運の醸成および当楽曲の普及を目的として使用する場合は、楽曲の使用、複製および第三者への配布など、自由にご活用いただけます。ただし、「福井県の品位を傷つける」「法令または公序良俗に反するおそれのある」使用は禁止されています。
