# "Kimi to Egaku Mirai e to" - Fukui Shinkansen Welcome Dance

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

`「君と描く未来へと」- 新幹線開業ウェルカムダンス`

This repository contains the official welcome dance song, "Kimi to Egaku Mirai e to" (To the Future I Draw With You), created to celebrate the opening of the Hokuriku Shinkansen line in Fukui Prefecture.
