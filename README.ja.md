# 「君と描く未来へと」- 新幹線開業ウェルカムダンス

`「君と描く未来へと」- 新幹線開業ウェルカムダンス`

音源および歌詞カードに関する著作権およびその他一切の権利は福井県が保有しております。

北陸新幹線の開業機運の醸成および当楽曲の普及を目的として使用する場合は、楽曲の使用、複製および第三者への配布など、自由にご活用ください。なお、「福井県の品位を傷つける」「法令または公序良俗に反するおそれのある」使用は禁止します。
